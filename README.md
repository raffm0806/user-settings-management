# User Settings Management App

A lightweight Python script designed to manage user configurations (add, update, delete, and view settings) with case-insensitive key handling. Built as a required project for the **freeCodeCamp Scientific Computing with Python** certification.

## 🛠️ Features

* **Case-Insensitive Operations:** Converts all keys and values to lowercase for consistency.
* **Add Settings:** Adds new key-value pairs without overwriting existing ones.
* **Update Settings:** Updates existing configuration keys safely.
* **Delete Settings:** Removes targeted settings with clear status feedback.
* **View Settings:** Formats and displays all active user settings neatly.

## 💻 Tech Stack

* **Language:** Python 3
